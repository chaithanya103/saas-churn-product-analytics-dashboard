# SaaS Customer Retention & Product Analytics Dashboard

## Overview
This project analyzes customer churn, product engagement, and revenue drivers for a SaaS business using Power BI.

## Dashboard Structure
The dashboard is divided into three key sections:

### 1. Business Overview
- Customer metrics (Total Users, Churn Rate, MRR, ARPU)
- Revenue distribution across subscription plans
- Churn distribution

### 2. Customer Retention Analysis
- Churn by tenure (when users churn)
- Churn by subscription plan (who churns)
- Churn by engagement (why users churn)

### 3. Product Usage & Engagement
- User behavior analysis (usage distribution, login frequency)
- Power users vs casual users
- Engagement vs revenue insights

## Key Insights
- Churn rate is high (~37%), impacting revenue significantly
- Basic plan users show the highest churn (~74%)
- Low engagement is the strongest driver of churn
- High-engagement users generate significantly higher revenue

## Recommendations
- Improve onboarding experience to increase early engagement
- Focus on converting casual users into power users
- Enhance value proposition for lower-tier plans
- Implement product engagement strategies (notifications, reminders)

## Tools Used
- Power BI
- DAX
- Data Visualization & Product Analytics
